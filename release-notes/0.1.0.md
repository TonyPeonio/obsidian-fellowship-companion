First release.

- **Add an opportunity**: paste a call for applications (and optionally its URL). Application deadline and letters deadline (told apart by wording), amount with currency, eligibility statements and required materials (CV, transcript, personal statement, research statement, N letters, budget) are read deterministically; one local-model call (Ollama, JSON mode, thinking off) fills name, funder and keywords and adds what the regexes missed, with regex results winning on conflict and the model's dates re-parsed. Writes `Fellowships/<Funder> - <Name>.md` with the call verbatim, Eligibility and Materials lists (plain bullets, never checkboxes, so nothing lands in your task queries), a Letters table and a Timeline. Works without Ollama (regex pass only).
- **Change status**: considering → preparing → submitted → interview → awarded → declined → withdrawn; sets `submitted_on` and appends a dated Timeline line.
- **Check materials**: matches the required materials against notes and files in the Materials folder by name keywords and rewrites `## Materials` as plain bullets: found items link to the file, missing items say what name would match, and letters report how many are received. The board counts an item as ready when it links to a file or every letter is in. Deterministic.
- **Draft letter requests**: one request note per named recommender without an "asked on" date, under `Fellowships/Letters/`, with the fellowship summary, the letters deadline, what the call asks letters to address (model points checked against the call's wording, or the call's own sentences), the materials you will attach and a message to copy; marks "asked on" with today. Never sends anything; re-running writes nothing twice.
- **Open the board**: rewrites `Fellowships/Board.md` with what is due in 30 days, whose letters are due in 14 days, and a table per status with deadline, days left, letters received (n of m) and materials ready (n of m). Optional `.ics` export of both deadline kinds.
- **Screen eligibility**: compares each criterion the call states with `Profile.md`. GPA, citizenship, degree level, year, age and field are decided by rules; the local model assesses the rest; only criteria that appear in the call text are quoted.
